# 🩺 AI Disease Predictor

An AI-powered web application that predicts diseases based on user-selected symptoms using a Deep Learning (Neural Network) model, and provides relevant descriptions and precautions for the predicted disease.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Aryan-baitha/AI-Disease-Predictor/blob/main/Disease_Symptom_Prediction.ipynb)

---

## 📌 Overview

This project takes a patient's symptoms as input and predicts the most likely disease using a trained neural network. Along with the prediction, it also shows a short description of the disease and precautionary steps to follow — making it a simple, end-to-end symptom checker.

The model is trained on a public symptom-disease dataset, wrapped in a Streamlit web app, and deployed directly from Google Colab using `localtunnel`.

---

## ✨ Features

- 🔍 Select multiple symptoms from a searchable dropdown
- 🧠 Deep Learning model predicts the most probable disease
- 📖 Auto-fetches a description of the predicted disease
- 🛡️ Lists precautions/next steps for the predicted disease
- 🌐 Simple, interactive Streamlit web interface
- ☁️ Deployable directly from Google Colab (no separate server needed)

---

## 🗂️ Dataset

The project uses 4 CSV files:

| File | Description |
|---|---|
| `dataset.csv` | Main dataset containing diseases mapped to their symptoms |
| `symptom_Description.csv` | Short description for each disease |
| `symptom_precaution.csv` | 4 precautions listed per disease |
| `Symptom-severity.csv` | Severity weight assigned to each symptom |

---

## 🧠 How It Works

1. **Data Preprocessing**
   - Missing values are cleaned and all symptom columns are converted into a single **binary matrix** (one-hot style) — each unique symptom becomes a column with `1`/`0` indicating its presence.
   - Disease names are label-encoded into numeric classes using `LabelEncoder`.

2. **Model Architecture**
   A fully connected neural network built with TensorFlow/Keras:
   - Input Layer → Dense(128, ReLU) → Dropout(0.2)
   - Dense(64, ReLU) → Dropout(0.2)
   - Output Layer → Dense(num_classes, Softmax)
   - Optimizer: `adam` | Loss: `sparse_categorical_crossentropy`
   - Trained for 30 epochs on an 80/20 train-test split

3. **Prediction Pipeline**
   - User-selected symptoms are converted into the same binary input format
   - Model predicts the disease with the highest probability
   - Description and precautions are fetched from the respective CSV files based on the predicted disease

4. **Deployment**
   - The trained model, label encoder, and symptom list are saved as `.h5` / `.pkl` files
   - A Streamlit app (`app.py`) loads these files and serves an interactive UI
   - The app is tunneled to a public URL using `localtunnel` directly from Colab

## 🚀 Getting Started

### Option 1: Run on Google Colab (Recommended)

1. Click the **"Open in Colab"** badge above
2. Upload the 4 dataset CSV files to the Colab session (`/content/`)
3. Run all cells in order — this will train the model, save it, and launch the Streamlit app
4. Open the `localtunnel` link generated in the last cell and enter the displayed IP as the tunnel password

### Option 2: Run Locally

```bash
# Clone the repository
git clone https://github.com/Aryan-baitha/AI-Disease-Predictor.git
cd AI-Disease-Predictor

# Install dependencies
pip install pandas numpy scikit-learn tensorflow matplotlib streamlit

# Run the notebook to train and save the model, then run the app
streamlit run app.py
```
